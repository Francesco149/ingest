# Purpose
Transcribe dialogue from manga gallery content based on reasoning and descriptions.

# Pool
vision

# Input
- dep_* (dict): Task outputs containing 'reasoning_text' and 'descriptions'.
- metadata (dict): Gallery metadata including title and tags.
- url_slug str (mandatory): The source of truth for the pipeline.

# Output
- transcript_text (str): The generated dialogue transcript.
- reasoning_text (str): The reasoning generated by the LLM.
- start_page (int): The starting page number.
- url_slug (str): The url slug.
