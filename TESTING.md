# Testing

This repo is developed on NixOS. Use the repo-local shell for deterministic
test tooling:

```bash
nix-shell
```

The shell includes Python, pytest, ffmpeg/ffprobe, espeak-ng, whisper-cpp,
yt-dlp, and a packaged `llama_video` Python module for integration tests.
`shell.nix` also creates `/tmp/ffbins/ffmpeg` and `/tmp/ffbins/ffprobe`, then
prepends `/tmp/ffbins` to `PATH`; this works around llama-video deriving
`ffprobe` by replacing `ffmpeg` in the executable path.

## Baseline

Run before finishing Python or test changes:

```bash
nix-shell --run 'python -m compileall run_api.py modules'
nix-shell --run 'pytest'
git diff --check
```

Default `pytest` runs fast mocked tests and fixture generation tests. Slow
endpoint-backed tests are collected but skipped by default.

## Endpoint Tests

Host-local endpoints used by opt-in integration tests:

```text
reasoning LLM: http://localhost:8080
llama-video:   http://localhost:7080
embeddings:    http://localhost:6080
```

These were also reachable from the Codex environment via `10.0.10.56`.

Run all endpoint-backed tests:

```bash
INGEST_RUN_ENDPOINT_TESTS=1 pytest tests/integration -q -s
```

Run manga endpoint test with optional embedding assertion:

```bash
INGEST_RUN_ENDPOINT_TESTS=1 \
INGEST_USE_EMBEDDING_ASSERTIONS=1 \
pytest tests/integration/test_manga_endpoint_fixture.py -q -s
```

Embedding defaults:

```text
INGEST_EMBEDDINGS_BASE=http://localhost:6080
INGEST_EMBEDDINGS_MODEL=nomic-embed-text-v1.5.f16.gguf
INGEST_EMBEDDING_MIN_SIMILARITY=0.65
```

Run video endpoint tests, including llama-video visual understanding:

```bash
INGEST_RUN_ENDPOINT_TESTS=1 \
INGEST_RUN_LLAMA_VIDEO_TEST=1 \
pytest tests/integration/test_video_endpoint_fixture.py -q -s
```

The video integration uses the local Whisper model by default:

```text
/opt/ai-lab/models/whisper/ggml-medium.bin
```

Override paths if needed:

```bash
INGEST_WHISPER_BIN=/path/to/whisper-cli
INGEST_WHISPER_MODEL=/path/to/ggml-medium.bin
INGEST_LLAMA_VIDEO_BASE=http://localhost:7080
INGEST_REASONING_LLM_BASE=http://localhost:8080
```

## Synthetic Fixtures

Manga fixture:

- Generated by `tests/fixtures/synthetic_manga.py`.
- Three PNG pages plus `reference.json`.
- Small misleading corner page markings are present; the correct page range
  exists only in the task prompt.

Video fixture:

- Generated by `tests/fixtures/synthetic_video.py`.
- 6 seconds, 10 fps, `960x540`.
- Ria moves toward a blue key; Kai opens a red door.
- Audio deliberately says only: "This is my stickman animation. Pay close
  attention to it."
- Audio is padded to the full 6 seconds so muxed video duration matches the
  video-only duration.

To generate a local preview copy:

```bash
nix-shell --run 'python - <<'"'"'PY'"'"'
from pathlib import Path
from tests.fixtures.synthetic_video import generate_synthetic_video_fixture
generate_synthetic_video_fixture(Path("tmp_synthetic_video_fixture"))
PY'
```

Remove temporary preview folders after inspection.
